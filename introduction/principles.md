# Principles

Agent World Theory is built on a small set of non-negotiable principles.

## 1. The world must be explicit

An agentic system must define the world in which agents operate.

The world must describe what exists, who owns it, what state it is in, what policies apply, what actions are allowed, and how outcomes are observed.

## 2. Agents are workers, not worlds

An agent is not the system.

An agent is a worker inside a governed world. It may reason, recommend, act, observe, or learn, but it must not own the full operating boundary.

## 3. Context is structured state

Context is not only prompt text.

Context is structured, governed, retrievable state connected to entities, decisions, policies, memory, and outcomes.

## 4. Decisions are first-class objects

A decision must be stored, explained, approved, executed, measured, and learned from.

Every important action should connect back to a decision record.

## 5. Boxes are composable capability boundaries

A box is the smallest reusable building block of a world.

A box should be understandable, testable, replaceable, observable, and governed.

## 6. Buildpacks assemble worlds

A buildpack is the BuildKit for agentic systems.

It composes boxes into runnable capabilities, applications, or environments.

## 7. Fabric connects everything

Fabric is the operating layer that connects boxes, buildpacks, agents, humans, decisions, policies, actions, and outcomes.

## 8. Safety is mandatory before testing

Testing is restricted to researchers who have implemented and acknowledged all required Agent Safety Protocols defined in this GitHub organization.

If safety conformance fails, testing is blocked.

## 9. Every action must be observable

Actions must produce traces, audit records, policy results, decision references, and outcome records.

## 10. Learning must be governed

Memory and learning loops must be explicit, auditable, scoped, and reversible where required.
