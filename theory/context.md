# Context

Context is structured state that gives meaning to signals, decisions, actions, and outcomes inside a world.

## Definition

Context includes time, location, identity, ownership, permissions, history, relationships, and constraints relevant to an interaction.

## Principles

- Context is not only prompt text
- Context must be structured, governed, retrievable state
- Context must be connected to entities, decisions, policies, memory, and outcomes
- Context must be bounded by domain and policy

## Context and agents

An agent receives context from the world, not from its own memory. The world provides the context the agent needs to make decisions and take actions.
