# Zip and Zig Design Doctrine

Zip and Zig are the design principles for all atomic units in the Fabric.

## Definition

**Zip** = small, fast, sealed, direct.

**Zig** = adaptive, routed, policy-aware, evidence-backed.

## Design rule

Atomic units should zip in size and zig through governed paths.

## Zip properties

- tiny scope
- fast start
- low dependency
- bounded runtime
- minimal authority

## Zig properties

- route by policy
- adapt by trust
- move by port
- stop at gate
- emit evidence every turn

## Application

**Atomic Agent** thinks small (zip) and routes through governance (zig).

**Atomic Kube** runs small (zip) and delivers through governed paths (zig).

## Doctrine

```
Atomic agent thinks small.
Atomic kube runs small.
Zip in scope.
Zig through governance.
Prove everything.
```
