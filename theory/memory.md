# Memory

Memory is reusable knowledge derived from context, decisions, outcomes, traces, and human review.

## Definition

Memory must be governed, scoped, auditable, and reversible where required. Memory is not an unbounded prompt cache. Memory is structured, policy-bound knowledge.

## Memory principles

- Memory must be explicit, not hidden
- Memory must be scoped by domain
- Memory must be governed by policy
- Memory must be auditable
- Memory must be reversible where required
- Memory must feed learning loops
