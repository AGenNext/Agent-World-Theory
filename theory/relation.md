# Relation

Relation is the governed connection between primitives inside the Fabric.

Relation says what is connected. Without Relation, the graph only describes disconnected nodes.

## Definition

Relation = who or what is connected to whom or what, under which domain and rule.

## Examples

- User HAS_ROLE Teacher
- Teacher OPERATES Agent
- Agent USES Tool
- Agent ACCESSES Data
- Device BELONGS_TO Workplace
- Wallet RECEIVES Benefit
- Provider OFFERS Capability
- Kube RUNS_ON Runtime
- OpenBox CONTAINS Artifact
- Evidence PROVES Exchange

## Relation rules

- Every relation must be domain-scoped
- Every relation must be policy-governed
- Every relation must be observable
- Every relation must be revocable
- No relation may exist outside a declared domain

## Relation and Path

Relation creates structure.
Path creates movement.

A path is a traversal across relations. Without relations, no path can exist.

## Relation and Identity

A relation always connects two or more identities. An identity with no relations is isolated and cannot participate in the Fabric.
